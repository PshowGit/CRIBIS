Prima di iniziare

Per usare il programma ti servono quattro cose:

Windows 10 o 11Il programma è fatto per Windows e non funziona su Mac.
Google ChromeDeve essere installato. Il programma lo usa in automatico per navigare su CRIBIS X.
InternetServe per collegarsi a CRIBIS X e, la prima volta, per scaricare il componente che guida Chrome.
Un account CRIBIS XNome utente e password con cui entri di solito sul portale.

Installazione

  1. Scarica il programma

    Premi Scarica per Windows in alto o in fondo a questa pagina. Si scarica un file chiamato CRIBIS_Export_Setup_1.0.3.exe.

  2. Aprilo

    Fai doppio clic sul file scaricato. Se Windows mostra “Windows ha protetto il PC”, premi Ulteriori informazioni e poi Esegui comunque. Succede perché il programma è nuovo e non ha ancora una firma digitale.

  3. Segui la procedura guidata

    Premi Avanti fino alla fine. Puoi lasciare la cartella proposta e, se vuoi, spuntare la creazione dell'icona sul desktop.

  4. Avvia CRIBIS Export

    Alla fine dell'installazione lascia la spunta su “Avvia CRIBIS Export”. Le volte successive lo trovi nel menu Start o sul desktop.

Aggiornare il programma. Quando esce una nuova versione, scarica il nuovo file e avvialo allo stesso modo: sostituisce quello vecchio e le tue credenziali restano salvate.

Come si usa

  1. Inserisci le credenziali

    Scrivi utente e password di CRIBIS X e premi Salva Credenziali. Lo fai una volta sola: il programma se le ricorda sul tuo computer.

  2. Carica il tuo elenco

    Trascina il file nell'area tratteggiata, oppure clicca sull'area per sceglierlo dal computer. Per fare una prova trovi un dati.txt di esempio nella cartella del programma. Sotto compare quante voci ha trovato, ad esempio “24 IVA trovate” oppure “12 Ragioni sociali trovate”.

  3. Scegli se vedere il browser

    L'interruttore Mostra il browser durante l'esecuzione è acceso di default: vedrai Chrome aprirsi e cercare da solo. Spegnilo se preferisci che lavori in secondo piano.

  4. Premi Avvia

    Il programma entra in CRIBIS X e cerca le voci una alla volta. Se il browser è visibile, non chiuderlo e non usarlo mentre lavora.

  5. Controlla l'avanzamento

    La barra mostra la percentuale e il riquadro nero racconta cosa sta succedendo. Quando ha finito, sotto la barra compare una riga verde con l'esito.

  6. Apri il risultato

    Premi Apri file Excel in alto a destra nel riquadro del processo. Si apre il foglio con tutti i dati raccolti.

Ci vuole pazienza. Tra una ricerca e l'altra il programma aspetta da 4 a 9 secondi, e ogni 100 ricerche fa una pausa di 3 minuti. È voluto: evita di sovraccaricare il portale e di essere bloccati. Per elenchi lunghi puoi lasciarlo lavorare e fare altro, soprattutto con il browser nascosto.

Il file da caricare

Il programma legge quattro tipi di file. In tutti i casi cerca una voce per riga, e ogni voce può essere una partita IVA, un codice fiscale o una ragione sociale.

TipoCosa legge
.txtUna voce per riga. Le righe vuote sono ignorate.
.xlsx e .xlsLa prima colonna che contiene dei dati. Le altre colonne vengono ignorate.
.csvLa prima colonna che contiene dei dati, con il separatore riconosciuto in automatico.

Un titolo in cima alla colonna

Nei file Excel e CSV puoi scrivere un titolo nella prima riga, per esempio “Partita IVA”: viene saltato da solo. Succede quando la prima riga non contiene nessuna cifra. Nei file .txt ogni riga è una voce, quindi non scrivere titoli.

Gli zeri iniziali. Se in Excel le partite IVA perdono lo zero davanti, formatta la colonna come “Testo” prima di salvare il file. Una partita IVA ha sempre 11 cifre.

Il risultato

Il programma crea un file Excel chiamato cribis_dati_export.xls con una riga per ogni voce del tuo elenco, nello stesso ordine. La prima colonna ripete la voce che hai cercato, così sai sempre a quale riga corrisponde cosa.

Dove si trova il file

Il modo più semplice è il pulsante Apri file Excel. Il file sta nella cartella del programma: %LOCALAPPDATA%\Programs\CRIBIS Export. Se lo copi altrove, fallo con il programma fermo.

Chiudi il file prima di avviare. Se il foglio Excel è aperto, il programma non riesce ad aggiornarlo e si ferma subito con un errore. Puoi aprirlo per dare un'occhiata mentre lavora, ma poi chiudilo prima che continui. A ogni nuova esportazione il file precedente viene sostituito: copialo prima se ti serve.

Problemi comuni

Windows dice che l'app non è riconosciuta

Premi Ulteriori informazioni e poi Esegui comunque. Il programma non ha una firma digitale, quindi Windows lo segnala la prima volta.

Compare “Login fallito”

Controlla utente e password, correggili e premi di nuovo Salva Credenziali. Verifica anche di riuscire ad accedere a CRIBIS X dal browser. Se la password è stata cambiata di recente, usa quella nuova.

Compare un errore sul file Excel

Il file cribis_dati_export.xls è probabilmente aperto in Excel. Chiudilo e premi di nuovo Avvia.

Alcune righe del risultato sono tutte N/D

Per quella voce il portale non ha restituito nessuna azienda. Controlla come è scritta (cifre complete, nessuno spazio di troppo) e riprova da sola. Se N/D compare su moltissime righe, apri il file di log e segnala il problema.

Ho aggiornato Chrome. Devo fare qualcosa?

No. A ogni avvio il programma si procura da solo il componente adatto alla versione di Chrome che hai. Serve solo la connessione a Internet.

Ho chiuso Chrome o il programma durante l'esportazione

Le righe già raccolte restano nel file Excel. Riapri il programma, ricarica l'elenco e ricomincia. Per non rifare tutto, togli dall'elenco le voci già elaborate.

Come disinstallo il programma?

Da Impostazioni → App → App installate, scegli CRIBIS Export e premi Disinstalla. Vengono cancellate le credenziali salvate e il registro. Il file Excel dei risultati resta nella cartella.

Devo segnalare un problema, cosa invio?

Premi Apri file di log, salva il file cribis_export.log e invialo a Calogero Catanzaro. Non contiene la tua password.

Pronto a provare?

Scarica l'installer, avvialo e carica il tuo primo elenco. Bastano pochi minuti.
